# DATA PRIVACY POLICY — Remote Maternal Health Monitoring and Escalation System

---

## Overview

This document explains how patient data is handled in this project.

This project is a **student-level prototype** built for educational purposes.
It follows a **privacy-by-design** approach, meaning that privacy protections
are built into the system from the very beginning — not added as an afterthought.

---

## Key Principle: Simulated Data Only

> **This project will NEVER use real patient data.**

All patient records used in this project are **entirely simulated (fake)**.
The data is generated by a Python script and does not correspond to any real person.

---

## What We Will NOT Store

The system will NOT collect, store, or process any of the following:

| Type of Information         | Example                          | Used in This Project? |
|-----------------------------|----------------------------------|-----------------------|
| Patient full name           | "Priya Sharma"                   | ❌ No                 |
| Phone number                | +91 98765 43210                  | ❌ No                 |
| Home address                | Village name, district, state    | ❌ No                 |
| Aadhaar number              | 1234 5678 9012                   | ❌ No                 |
| Hospital registration number| MH/2024/00123                    | ❌ No                 |
| Real medical records        | Doctor's notes, lab reports      | ❌ No                 |
| Photos or biometric data    | Fingerprints, face scans         | ❌ No                 |
| Any other identifying info  | Email, date of birth             | ❌ No                 |

---

## How Patients Are Identified

Patients in this prototype are identified only using **anonymous IDs**:

```
P001
P002
P003
...
P100
```

These IDs are randomly assigned numbers. They do not correspond to any real person.

---

## Minimum Necessary Information

Future simulated data will contain **only the minimum fields** required to demonstrate
the prototype. Extra fields that are not needed for the system to function will not be added.

Examples of fields that **will** be simulated:
- Anonymous patient ID (e.g., P001)
- Gestational age (weeks of pregnancy)
- Blood pressure readings (simulated values)
- Heart rate (simulated value)
- Patient-reported symptoms (simulated responses)
- Visit date
- Risk level (assigned by the system)

---

## Data Storage

- Simulated data files will be stored **locally on the development machine only**
- No data will be uploaded to any cloud service, database, or external server
- No real database or login system is used in this prototype

---

## Disclaimer

> This prototype is **not a medical diagnostic system** and should **not** be used
> to make real clinical decisions.
>
> If you are a patient or caregiver, please consult a qualified medical professional
> for any health concerns.
